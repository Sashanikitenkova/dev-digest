# Smoke check — not a benchmark

One run per configuration, made right after the eval cases moved into
`../../onion-architecture/evals/`. Its only job is to prove the prompts and
paths in `eval.md` still work end to end.

One run per configuration is far too few to compare the configurations — see
`../iteration-1/` for the real 16-run benchmark, and re-run that when you want
numbers.
