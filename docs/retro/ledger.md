# Workflow retro ledger

Append-only record of multi-agent workflow runs, written by
[`/workflow-retro`](../../.claude/skills/workflow-retro/SKILL.md). Newest entries
at the end.

Each entry is self-contained: it names the run, the mode the retro used, the
headline metrics, and only the insights and proposals worth reading months
later. The full report stays in the session it came from — this file is the
memory, not the transcript.

Per-agent token figures come from one of two definitions that disagree by more
than an order of magnitude, so every entry names which one it used. Never
compare a number from one definition against a number from the other.

Never edit or delete a past entry. A conclusion that later proves wrong gets a
new dated entry naming the one it supersedes.
